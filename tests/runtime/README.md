# 本地模型运行时验收

先安装主插件，再用 DSH 插件管理器安装本目录。该临时测试 bundle 同时运行两个场景，仅使用本地模型适配器，不调用付费 API，不向现有业务会话发送消息。

- `slow-result.json`：第一次请求错误；后台通知启动第二次请求，并让它运行 6.5 秒，超过默认 5 秒恢复等待。之后必须出现 Goal resume、第三次请求和 complete。
- `result.json`：八次错误与八次后台通知交替发生，必须出现八次 resume、17 次模型请求及 complete。

默认设置下最长约 95 秒后写入结果，检查 `ok: true` 和 `humanMessages: 0`。如果修改过等待参数，需相应扩大测试超时。结果文件已加入 gitignore。完成后用插件管理器卸载 `dsh-auto-continue-runtime-check`。测试会自行释放创建的 Agent；本目录为临时验收包，因此不包含产品图标和语言资源。

1.4.0 发布验收结果：45 项单元测试通过；旧版 1.3.2 的慢通知场景停在 2 次请求、active/disarmed；1.4.0 同场景到达 3 次请求并完成；八次恢复场景完成于第 17 次请求，人类消息数为 0。
